  MainApp — Римские числа & Извлечение слов (Java GUI)
═══════════════════════════════════════════════════════════

ТРЕБОВАНИЯ:
  Java 11 или выше (JRE достаточно)
  Скачать: https://adoptium.net/

ЗАПУСК:
  Windows:   двойной клик по MainApp.jar
             или двойной клик по run.bat
             или в командной строке: java -jar MainApp.jar

  Linux/Mac: bash run.sh
             или: java -jar MainApp.jar

СТРУКТУРА АРХИВА:
  MainApp.jar             ← исполняемый файл (двойной клик!)
  run.bat                 ← запуск для Windows
  run.sh                  ← запуск для Linux/Mac
  MainApp.java            ← исходный код
  build.bat / build.sh    ← пересборка JAR из исходников (нужен JDK)
  test_data/
    test1_roman.txt       ← арабские числа → римские
    test2_arabic.txt      ← римские числа → арабские
    test3_words.txt       ← англ+рус текст, длина=3
    test4_edge.txt        ← граничные случаи
    test5_mixed.txt       ← Ё/ё, цифры в словах, спецсимволы
    output.txt            ← результат прогона тестов

ФУНКЦИОНАЛЬНОСТЬ:
  Вкладка 1 — Римские ↔ Арабские
    • Ввод чисел вручную или загрузка из файла
    • Конвертация в обе стороны
    • Сохранение результата в файл

  Вкладка 2 — Слова по длине
    • Ввод текста вручную или загрузка файла
    • Извлечение уникальных слов заданной длины
    • Формат файла: 1-я строка = длина, далее текст
    • Сохранение результата в файл

  Вкладка 3 — Тесты
    • 44 автоматических теста
    • Результат записывается в test_data/output.txt
